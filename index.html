Sharing a layout

Every layout in these tools encodes to a short SHOP1--style code and to a plain web link. Both open the exact same building on any machine, so a layout travels in an email with nothing to install.

  1. Open the Layouts tab in a tool.
  2. Copy link for a message, or Copy code to paste into the same tab somewhere else.
  3. Publish on GitHub adds it to the shared library here, where it shows up for everyone. If you can write to this repository it commits directly; if not, GitHub walks you into a pull request. No account details are ever stored in the page.
